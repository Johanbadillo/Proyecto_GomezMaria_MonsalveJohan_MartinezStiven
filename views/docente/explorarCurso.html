MÓDULO 2

UNITY

Unity es un motor de desarrollo de videojuegos y aplicaciones 3D/2D, conocido por su versatilidad y facilidad de uso. Permite crear juegos y experiencias interactivas para múltiples plataformas, como PC, consolas, móviles, web, y realidad virtual. Su entorno de desarrollo intuitivo y su lenguaje de programación, junto con un amplio conjunto de herramientas visuales para diseño de niveles, animaciones, física, lo hacen popular entre desarrolladores independientes y grandes estudios. Ofrece una amplia gama de herramientas para crear juegos de cualquier tamaño y complejidad.

¿Qué incluye?

Editor Visual: Interfaz intuitiva para diseñar escenas, niveles y objetos en 2D y 3D. Sistema de Materiales: Soporte para gráficos con calidad de pipeline como URP (Universal Render Pipeline) y HDRP (High Definition Render Pipeline). Sistema de Física: Herramientas para 2D y 3D, incluyendo colisiones y simulaciones con PhysX para 3D y Box2D para 2D. Scripting en C#: Programación flexible para lógica de juego y comportamientos personalizados. Herramientas de Animación: Sistema de animación para personajes y objetos, con soporte para animaciones por keyframes o rigging. Multiplataforma: Publicación en PC, consolas (PlayStation, Xbox, Nintendo Switch), dispositivos móviles (iOS, Android), web y VR/AR. Asset Store: Mercado integrado con componentes como modelos 3D, texturas, scripts y sistemas de sonido completos. Sistemas de Partículas y Efectos Visuales: Creación de efectos como fuego, humo y explosiones. Herramientas de Audio: Integración de audio espacial y sistemas de mezcla de sonido. Unity Hub: Gestor para administrar proyectos, versiones y licencias.
