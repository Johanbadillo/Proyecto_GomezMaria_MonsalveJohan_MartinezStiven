# **LMS PORTAL** #

# **Descripción** #

LMS PORTAL es una plataforma web educativa diseñada para la gestión de cursos de programación. El sistema permite la interacción de tres tipos de usuarios: **estudiantes**, **docentes** y **administradores**, ofreciendo un entorno intuitivo y organizado para la enseñanza y el aprendizaje.

El proyecto está desarrollado en HTML, CSS y JavaScript puro, con un enfoque modular en el diseño de interfaces y funcionalidades adaptadas según el rol del usuario.
