# PROYECTO LMS - Sistema de gestion del aprendizaje

Este proyecto consiste en el desarrollo de un **Learning Management System (LMS)** moderno y funcional, diseñado para facilitar la gestión educativa digital. A través de una interfaz intuitiva y responsiva, permite a instituciones, docentes y estudiantes interactuar eficientemente en un entorno virtual de enseñanza y aprendizaje.

## Descripcion general
En un contexto de transformación digital, los LMS se han convertido en herramientas clave para la educación. Este proyecto propone una solución adaptable que soporte múltiples perfiles de usuario, incluyendo:

- Administradores
- Docentes
- Estudiantes

El sistema cubre funcionalidades desde la gestión de cursos y contenidos hasta el seguimiento de tareas y evaluaciones académicas.


### Tecnologías Utilizadas

- HTML5 / CSS3 / JavaScript
- JSON-Server o Mock API (para persistencia de datos simulada)
- Figma

## Contenido:

| Indice | Titulo  |
|--|--|
| Módulos del LMS | Estadísticas clave: cursos activos, usuarios, progreso general. |
| Gestión de Cursos | Crear y editar cursos (categorías, duración, etiquetas, visibilidad). |
| Gestión de Docentes | Registro y edición de docentes. Panel con carga académica, desempeño y cursos asignados |
| Gestión de Estudiantes | Inscripción y seguimiento de estudiantes. Estado de actividades: completadas, pendientes retrasadas |
| Lecciones y Contenidos | Estructuración por módulos y lecciones. Soporte para comentarios. Estado: publicado. |
| Tareas y Evaluaciones | Creación de tareas con rúbricas y fechas límite. Vista de entregas y retroalimentación. |
| Módulo Administrador | Gestión centralizada de cursos, estudiantes y contenidos. |
